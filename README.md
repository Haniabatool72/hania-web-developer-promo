# Hania Batool — Web Developer Promotional Ad

An animated, interactive promotional webpage showcasing Hania Batool's web development services, design concepts, and professional workflow.

## ✨ Overview

This project presents a creative advertisement for web development services using a vertical 9:16 layout, animated transitions, glowing gradients, and modern visual effects.

The experience highlights website development services and encourages potential clients to connect for their website projects.

## 🚀 Features

- Animated promotional scenes with automatic transitions
- Replay button to restart the presentation
- Responsive scaling for different screen sizes
- Animated gradient backgrounds and floating particles
- Modern browser mockup and website design previews
- Web development services showcase
- Step-by-step development process
- Website categories and sample design concepts
- Contact call-to-action
- Smooth CSS animations and transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Keyframe Animations
- Responsive Layout Techniques
